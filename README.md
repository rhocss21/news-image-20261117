A newspaper front page summing up Tuesday 17 November 2026 in one image:
35 verified stories across 6 continents, led by the Kerch Bridge strikes,
with a numbered world map. Every story was first reported on 17 November
2026. The page is drawn with Pillow by `draw.py` (crisp vector text, no
garbled AI text) and `main.py` copies the finished `entry.png` to the
output directory. Built for make.fun's "Sum up 17 November's world news in
one image" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
